# رياضيات تانية — تطبيق تدريب الصف الثاني الابتدائي (منهج مصر، الترم الأول)

تطبيق أندرويد أوفلاين بالكامل لطفل واحد. قواعد المشروع في `CLAUDE.md`، والمنهج في `docs/curriculum.md`.

## ما يحتويه هذا الإصدار (APK الأول)
| الدرس | المحتوى |
|---|---|
| ١ — العدّ وإكمال الرسم البياني | مشهد عدّ بالشطب، إكمال رسم بالدوائر من أسفل لأعلى |
| ٢ — قراءة الرسم والجدول | من الرسم للجدول، الصنف الناقص، الأكثر/الأقل، كم عدد، المجموع، الفرق، أيهما أكثر، صنفان متساويان، الترتيب بالأسماء، "إذا انضم..."، الرسم أم الجدول |
| ٣ — المقارنة بين رسمين | الأكبر في رسم، المتساوي في الرسمين، المجموع في الرسمين، بكم يزيد، أكبر فرق، الترتيب |
| ٤ — الجمع بدون حمل | جدول قيمة مكانية، شبكة رأسية (الآحاد أولاً)، تحويل لرأسي بالسحب، اكتشف الخطأ، صِل المتساوي، مسائل لفظية |
| ٥ — الجمع بالحمل | الحمل في دائرة فوق العشرات، حالتا (آحاد = ١٠) و(آحاد > ١٠) |
| ٦ — خاصية الإبدال | صِل بدون حساب، أكمل الفراغ، مسألة بطريقتين |

الدرسان ١ و٤ مفتوحان من البداية (الطفل الآن في الفصل ٢). الباقي يُفتح بالإتقان أو من شاشة ولي الأمر.

## الأوامر
```
npm install
npm test                         # المحرك + اختبار ١٠٠٠ سؤال لكل درس
npm run build && npm run test:ui # اختبار العرض في Chromium (يحتاج CHROMIUM=مسار المتصفح خارج هذه البيئة)
npm run apk:debug                # يحتاج Android SDK 36 و JDK 21
```

## بناء الـ APK
كل push يغيّر `kids-math/` يشغّل workflow ‏`kids-math APK` في GitHub Actions: يشغّل الاختبارات ثم يبني `app-debug.apk`
ويرفعه باسم **kids-math-debug-apk** (صفحة الـ run ← Artifacts). الملف يُنزَّل مضغوطاً (zip) وبداخله الـ APK.

التوقيع بمفتاح ثابت داخل المستودع (`android/app/kids-math-debug.keystore`)، ورقم الإصدار يزيد مع كل بناء،
فكل APK جديد يُثبَّت **فوق** القديم ويبقى تقدّم الطفل. لا تحذف التطبيق قبل التحديث.

## تثبيته على التابلت (HONOR Pad X8a)
1. نزّل الـ zip من GitHub على الكمبيوتر أو الموبايل، وفكّه لتحصل على `app-debug.apk`.
2. انقله للتابلت: بكابل USB (اختر "نقل الملفات" على التابلت وانسخه لمجلد Download)، أو أرسله لنفسك عبر Bluetooth/مشاركة الملفات.
3. على التابلت افتح **الملفات** ← Download ← اضغط على `app-debug.apk`.
4. سيطلب السماح بالتثبيت من مصدر غير معروف: اضغط **الإعدادات** وفعّل "السماح من هذا المصدر" لتطبيق الملفات، ثم ارجع واضغط **تثبيت**.
   (أو من: الإعدادات ← الأمان ← المزيد من الإعدادات ← تثبيت التطبيقات من مصادر خارجية.)
5. قد يظهر تحذير "Play Protect" أو "حماية التطبيقات" لأن التطبيق غير منشور على متجر: اختر **تثبيت على أي حال**.
6. بعد التثبيت يمكن إطفاء خيار "المصادر غير المعروفة" مرة أخرى.

## قائمة فحص يدوية قبل إعطائه للطفل
- [ ] فعّل **وضع الطيران** ثم افتح التطبيق: الخط العربي يظهر صحيحاً، والأرقام كلها هندية (٠–٩).
- [ ] ابدأ درس "الجمع الرأسي بدون حمل": ٧٢ تظهر "٧٢" وليست "٢٧"، والآحاد (أزرق) يميناً، و+ يمين العدد الثاني.
- [ ] جرّب لمس خانة العشرات قبل الآحاد: يرفض ويقول "ابدأ بالآحاد".
- [ ] أجب خطأً مرة: يظهر تلميح محدد. خطأً مرة ثانية: يظهر الحل خطوة بخطوة.
- [ ] أكمل جلسة كاملة (١٢ سؤالاً أو ١٠ دقائق) حتى شاشة النهاية والنجوم.
- [ ] ابدأ جلسة، أجب سؤالين، ثم **أغلق التطبيق من قائمة التطبيقات الحديثة** وافتحه: يظهر "أكمل الجلسة" والنجوم محفوظة.
- [ ] أدر التابلت أفقياً وعمودياً أثناء سؤال: لوحة الأرقام تبقى ظاهرة وكبيرة.
- [ ] شاشة ولي الأمر: اضغط مطوّلاً ٣ ثوانٍ على ⚙️ ثم أجب سؤال الضرب. راجع الإتقان والأخطاء والجلسات.
- [ ] من شاشة ولي الأمر: **تصدير** نسخة احتياطية وتأكد أن الملف ظهر في مجلد Documents.
- [ ] جرّب الكتم 🔇 والصوت 🔊.
