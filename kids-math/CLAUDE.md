# kids-math — قواعد المشروع

تطبيق أندرويد شخصي (طفل واحد) لتدريب رياضيات الصف الثاني الابتدائي، منهج مصر، الفصل الدراسي الأول.
المصدر الوحيد للمحتوى: `docs/curriculum.md`. حدوده إلزامية.

## القيود (لا تُكسر)
- **أوفلاين بالكامل**: لا CDN، لا Google Fonts، لا Firebase، لا تحليلات، لا روابط خارجية. الخط Cairo مضمّن في `public/fonts`، والأصوات تُولَّد بـ WebAudio داخل التطبيق.
- **خفيف** (تابلت رام 4GB): Vanilla TypeScript فقط، بلا مكتبات UI أو رسوم. أنيميشن CSS بسيط، وإيموجي أو SVG للصور.
- **الأرقام هندية عربية (٠–٩) في كل نص معروض.** كل رقم يمر عبر `ar()` في `src/engine/digits.ts`. الإدخال عبر لوحة الأرقام الداخلية فقط (`src/ui/numpad.ts`)، لا لوحة مفاتيح النظام.
- الواجهة RTL، **لكن العمليات الرأسية وجداول القيمة المكانية `dir="ltr"` دائماً**: العشرات يساراً (وردي/بنفسجي) والآحاد يميناً (أزرق)، وعلامة + على يمين العدد الثاني. اختبار `tests/ui` يتحقق أن ٧٢ تظهر "٧٢" وأن الآحاد يميناً.
- الرسم البياني بالدوائر: الأصناف أفقياً تُقرأ من اليمين لليسار، والدوائر من أسفل لأعلى، والحد الأقصى ١٠ صفوف.
- الأزرار ≥ 64px، ولا عقوبات ولا فقدان نجوم.
- التخزين عبر `@capacitor/preferences` (`src/storage/store.ts`). أي تغيير في شكل الحالة يرفع `STATE_VERSION` ويضيف ترحيلاً في `migrate()` حتى لا يضيع تقدّم الطفل عند التحديث.

## البنية
```
content/            ملف JSON لكل درس + shared.json (الأسماء والمواضيع)
src/engine/         مولّد الأسئلة، التحقق، تشخيص الأخطاء، Leitner، الجلسة — كود نقي بلا DOM
src/ui/             الشاشات والمكونات (DOM مباشر عبر h())
src/storage/        الحالة، الحفظ، التصدير/الاستيراد
tests/              vitest (المحرك + اختبار ١٠٠٠ سؤال لكل درس) و tests/ui (Chromium حقيقي)
```

## إضافة درس جديد
1. أنشئ `content/ch{الفصل}-lesson{الدرس}.json` بنفس مخطط الدروس الموجودة (`src/engine/types.ts` → `Lesson`).
2. `questionTypes` تختار من الأنواع التي يعرفها المحرك (`Kind`). إن احتاج الدرس نوعاً جديداً: أضف مولّده في `src/engine/generators/`، ومُتحقّقه في `src/engine/check.ts`، ومكوّنه في `src/ui/kinds/`.
3. `limits` إلزامية: المولّد يرفض أي سؤال خارجها، و`tests/lessons.test.ts` يولّد ١٠٠٠ سؤال لكل درس ويتحقق منها تلقائياً.
4. كل بند "خطأ شائع" في المنهج يصبح عنصراً في `commonMistakes` بمعرّف من `ErrorType` وتلميح مخصص.
5. `order` يحدد مكانه في خريطة الدروس.

## الأوامر
- `npm test` — اختبارات الوحدة.
- `npm run build && npm run test:ui` — اختبار العرض في Chromium.
- `npm run apk:debug` — يحتاج Android SDK (منصة 36) و JDK 21.
